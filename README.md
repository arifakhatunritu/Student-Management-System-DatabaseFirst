# Student Management System (ASP.NET MVC)

The **Student Management System** is an **ASP.NET MVC** web application developed using the **Entity Framework Database-First** approach with **SQL Server** to manage student records and enrollments.

## Technology Stack
- **Backend:** C# (ASP.NET MVC)
- **Database:** Microsoft SQL Server
- **ORM:** Entity Framework (Database-First)
- **Frontend:** HTML, CSS, Bootstrap, JavaScript
